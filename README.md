# GDG PUP Photobooth

Next.js photobooth for **GDG on Campus PUP** events: capture photos, apply filters, and download shareable strips.

## Table of Contents

- [About](#about)
- [Features](#features)
- [Quick start](#quick-start)
- [Documentation](#documentation)
- [Contributors](#contributors)

## About

Event photobooth for GDG on Campus PUP. Guests take photos in-browser, pick filters, and download a shareable strip for social posts and event memories.

## Features

- Camera capture in the browser
- Photo filters
- Downloadable photobooth strips

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
