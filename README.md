## About

Event photobooth for GDG on Campus PUP. Guests take photos in-browser, pick filters, and download a shareable strip for social posts and event memories.

## Start here

- **Humans:** this README, then [docs/state.md](docs/state.md)
- **Agents:** [AGENTS.md](AGENTS.md) (state → index → FLAGS)
- **Contributors:** table below

## Features

- Camera capture in the browser
- Photo filters
- Downloadable photobooth strips

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
